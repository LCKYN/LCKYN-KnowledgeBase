# Ensemble Methods: Bagging & Boosting

## Overview
An **ensemble** combines many models (**base learners**) into one predictor that beats any single member. **Bagging** trains strong learners independently on resampled data and averages them to cut variance; **boosting** trains weak learners one after another, each correcting the current ensemble's errors, to cut bias.

## Key Concepts
- **Base learner** — the model being combined; almost always a decision tree.
- **Strong learner** — low bias, high variance (deep, unpruned tree). What bagging averages.
- **Weak learner** — high bias, low variance, only slightly better than chance (stump or shallow tree). What boosting stacks.
- **Diversity** — an ensemble only helps if its members make *different* errors. Row resampling, feature sampling, and sequential correction are all ways to get it.

## Bagging (Bootstrap Aggregating)
- Draw $B$ **bootstrap samples** — same size as the training set, sampled with replacement.
- Train one model per sample; models are independent, so training is fully parallel.
- Aggregate by averaging (regression) or majority vote (classification).

> [!INFO]
> Why it works: averaging $B$ models with variance $\sigma^2$ and pairwise correlation $\rho$ gives
> $$\text{Var} = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$
> More models shrink only the second term; the first is a floor set by how correlated the models are. Bias stays the same. See [[12.07 Bias-Variance Tradeoff]].

- **Random Forest** = bagging + a random feature subset at every split. Feature sampling lowers $\rho$, which is why it beats plain bagged trees.
- **Out-of-bag (OOB) error** — each bootstrap sample leaves out ~37% of rows; scoring every row on the trees that never saw it gives a validation estimate without a holdout set (see [[12.08 Cross-Validation]]).
- Adding more trees does not overfit — the error just plateaus.

## Boosting
- Start trivially — a constant prediction (gradient boosting) or equal sample weights (AdaBoost).
- Each round, fit a weak learner to whatever the current ensemble still gets wrong.
- Add it to the ensemble, scaled down, and repeat — training is inherently sequential.

| Aspect | AdaBoost | Gradient Boosting |
| :--- | :--- | :--- |
| **Targets errors by** | Reweighting samples — misclassified rows get heavier | Fitting each tree to the loss gradient (the residuals, for squared error) |
| **Combines learners by** | Weighted vote, weight set by each learner's accuracy | Sum of trees, each scaled by a learning rate |
| **Loss** | Exponential (fixed) | Any differentiable loss |
| **Typical learner** | Stumps (depth 1) | Trees of depth 3-8 |
| **Implementations** | scikit-learn `AdaBoostClassifier` | XGBoost, LightGBM, CatBoost |

- Primarily reduces **bias**; shrinkage and row/column subsampling add some variance control.
- Details of the gradient variant: [[12.11 Gradient Boosting]].

> [!WARNING]
> Boosting **can overfit**. Every round chases the remaining errors, including noise, so mislabeled rows and outliers get more and more attention. Control it with a low learning rate, early stopping, and subsampling.

## Other Ensembles
- **Voting** — average or vote across *different* model types (e.g., linear + tree + k-NN).
- **Stacking** — a meta-model learns how to combine the base models' out-of-fold predictions.

## Bagging vs Boosting

| Feature | Bagging | Boosting |
| :--- | :--- | :--- |
| **Training** | Independent, parallel | Sequential, each model depends on the previous ones |
| **Base learner** | Strong (deep trees) | Weak (shallow trees) |
| **Main effect** | Reduces **variance** | Reduces **bias** |
| **Data per model** | Bootstrap sample | Full data, reweighted or re-targeted on current errors |
| **Aggregation** | Equal-weight average / majority vote | Weighted sum of learners |
| **More learners** | Error plateaus | Eventually overfits |
| **Noisy labels / outliers** | Robust | Sensitive |
| **Tuning effort** | Low — good defaults | Higher — learning rate, tree count, depth interact |
| **Example** | Random Forest | AdaBoost, XGBoost, LightGBM |

## Practical Use Cases
- **Random Forest** — strong baseline with little tuning, noisy labels, need a quick OOB estimate, or want cheap parallel training.
- **Gradient boosting** — best accuracy on tabular data when labels are reasonably clean and there is time to tune.
- **Neither** — small or near-linear data (use a linear model), strict interpretability needs (single tree or linear), unstructured data such as images and text (deep learning).

> [!TIP]
> Diagnose before choosing: train error far below validation error is a variance problem → bagging. Both errors high is a bias problem → boosting.
