# Python 3.15 New Features

## Overview
Python 3.15 released **October 9, 2026**. Headline: **Tachyon**, a built-in sampling profiler (`profiling.sampling`). Also lazy imports, `frozendict`, UTF-8 by default, and a stable ABI for free-threaded builds. Builds on [[71.01 Python 3.14 New Features]].

## Release Highlights

| Category | Features |
|----------|----------|
| **Profiling** | `profiling` package (PEP 799): **Tachyon** sampling profiler + `profiling.tracing` (ex-`cProfile`) |
| **Syntax** | `lazy import` (PEP 810), `*`/`**` unpacking in comprehensions (PEP 798) |
| **Built-ins** | `frozendict` (PEP 814), `sentinel` (PEP 661) |
| **Runtime** | UTF-8 mode default (PEP 686), upgraded JIT, frame pointers on by default (PEP 831) |
| **Free-threading** | Stable ABI `abi3t` (PEP 803); macOS installers include free-threaded build |
| **Typing** | `TypedDict` extra items (PEP 728), `TypeForm` (PEP 747), disjoint bases (PEP 800) |

## Tachyon: `profiling.sampling`

> [!INFO]
> A **statistical sampling profiler** that reads the call stack of a process **from outside** at a fixed rate. Nothing is instrumented, so overhead is virtually zero and it is safe on production processes. By Pablo Galindo and László Kiss Kollár. It is a built-in alternative to `py-spy`.

### The `profiling` Package (PEP 799)

| Module | Kind | Use for |
|--------|------|---------|
| `profiling.sampling` | Sampling (Tachyon) | "Where does time go?" in real or production workloads |
| `profiling.tracing` | Deterministic (moved from `cProfile`) | Exact call counts, precise 1–2% comparisons |
| `cProfile` | Alias of `profiling.tracing` | Existing code keeps working |
| `profile` | Pure-Python tracer | **Deprecated**, removed in 3.17 |

### Commands

```bash
python -m profiling.sampling run script.py               # profile from startup
python -m profiling.sampling run -m pkg.module args      # profile a module
python -m profiling.sampling attach -d 30 --flamegraph -o prof.html <PID>
python -m profiling.sampling attach --live <PID>         # top-like TUI
python -m profiling.sampling dump -a <PID>               # every thread's stack, right now (hung process)
```

- **`-r` / `--sampling-rate`**: default `1khz`, accepts `10khz`, `20k`, and so on, up to about 1 MHz.
- **`-d` / `--duration`**: seconds to sample (default: until the process exits).
- **`-a`**: all threads (default: main thread only).
- **`--subprocesses`**: also profile child processes, one output file each (for worker pools).
- **`replay`**: turn a binary capture into any output format later.

### Modes (`--mode`)

| Mode | Counts | Use when |
|------|--------|----------|
| `wall` (default) | Real elapsed time, including I/O and blocking | Latency: "why is this request slow?" |
| `cpu` | Only time on CPU | Throughput: hot compute paths |
| `gil` | Time holding the GIL | Finding threads that starve the others |
| `exception` | Threads with an active exception | Costly exception-driven control flow |

Compare `wall` with `cpu`. If the `cpu` profile is thin, the process is **I/O-bound**, so optimizing Python code won't help much.

### Output Formats

| Flag | Output | Viewer |
|------|--------|--------|
| `--pstats` (default) | Table of direct and cumulative samples | Terminal / `pstats` |
| `--flamegraph` | Self-contained interactive HTML | Browser |
| `--heatmap` | Per-file HTML with line-level sample counts | Browser |
| `--gecko` | Gecko format | Firefox Profiler |
| `--collapsed` | One line per stack | FlameGraph, speedscope |
| `--live` | Real-time TUI with sorting and filtering | Terminal (Unix, `curses`) |

### Extras
- **`--async-aware`**: rebuilds stacks from **asyncio tasks** instead of the event loop. This shows *which* `await` is slow, which `py-spy` can't do.
- **`--native`**: adds `<native>` frames for time spent in C extensions (otherwise counted to the calling Python function).
- **`--opcodes`**: bytecode-level samples, including adaptive-interpreter specializations.
- **`<GC>` frames**: shown by default when garbage collection runs; hide them with `--no-gc`.

### Tachyon vs py-spy

| Aspect | Tachyon | py-spy |
|--------|---------|--------|
| Install | Built in (3.15+) | `pip install py-spy` (Rust binary) |
| Target versions | **Same minor version only**; free-threaded and GIL builds can't attach to each other | Many CPython versions |
| asyncio | Task-aware stacks | Shows the event loop only |
| Modes | wall / cpu / gil / exception | wall (`--idle`) / cpu |
| Outputs | pstats, flamegraph, heatmap, gecko, collapsed, live | SVG flame graph, speedscope, top |

> [!WARNING]
> - **Attach permissions**: Linux needs root, `CAP_SYS_PTRACE`, or `ptrace_scope=0` (in Docker, `--cap-add SYS_PTRACE`). macOS needs root. Windows needs admin or `SeDebugPrivilege`.
> - **Short scripts** (under about 1 s) collect too few samples. Loop the workload or use `profiling.tracing`.
> - **No exact call counts**: very short functions can run between samples and never show up.
> - **`--blocking`** pauses the target on every sample. Keep intervals of 1 ms or more.
> - **`--async-aware`** can't be combined with `--native`, `--no-gc`, `-a`, or `--mode=cpu|gil`.

## New Syntax

### Explicit Lazy Imports (PEP 810)
```python
lazy import json
lazy from pathlib import Path
data = json.loads("{}")  # json actually imported here, on first use
```
- Reduces startup time for CLIs and large apps without moving imports inside functions.
- Allowed **only at module scope**. Using `lazy` inside a function, class, or `try` block is a `SyntaxError`, and so are star imports and `__future__` imports.

### Unpacking in Comprehensions (PEP 798)
```python
flat = [*xs for xs in lists]              # was: [x for xs in lists for x in xs]
merged = {**d for d in dicts}
```

## Built-in Types

- **`frozendict`** (PEP 814): an immutable, hashable mapping. It inherits from `object`, not `dict`, so `isinstance(fd, dict)` is `False`. Use it as a dict key, a cache key, or a constant config.
- **`sentinel`** (PEP 661): unique sentinel values with a readable repr. Replaces `_MISSING = object()`.
- For **deeply immutable JSON**, use `json.loads(s, object_pairs_hook=frozendict, array_hook=tuple)`.

## Runtime & Performance

- **UTF-8 mode is the default** (PEP 686): `open()` without `encoding=` uses UTF-8 on every OS. To revert, set `PYTHONUTF8=0` or pass `-X utf8=0`.
- **JIT**: the experimental JIT is significantly upgraded, but still opt-in.
- **Frame pointers on by default** (PEP 831): `perf`, eBPF, and native profilers get reliable stacks.
- **GC**: the 3.14 **incremental GC was reverted** to the 3.13 generational GC because of memory-pressure reports. This also applies from 3.14.5.
- **Tail-calling interpreter** in the official 64-bit Windows builds.

### Free-Threading
- **`abi3t` stable ABI** (PEP 803): one extension wheel works across free-threaded CPython versions. Supported by meson-python, scikit-build-core, and Maturin (PyO3).
- macOS installers include free-threading support by default.

## Standard Library

| Module | Change |
|--------|--------|
| `math.integer` | New module for integer-only math functions (PEP 791) |
| `asyncio` | `TaskGroup.cancel()` for early termination |
| `re` | `prefixmatch()`; `match()` is soft-deprecated (the name was misleading) |
| `argparse` | `suggest_on_error=True` by default (typo suggestions) |
| `tomllib` | TOML 1.1 |
| `pdb` | New interactive shell (from the 3.14 REPL) by default |
| `sqlite3` CLI | Keyword and schema completion, colored output |
| `math` | `isnormal()`, `issubnormal()`, `fmax()`, `fmin()`, `signbit()` |

Error messages are also better: `AttributeError` suggests nested attributes (`.inner.area`), and JavaScript-style names (`push` → `append`).

## Migration Notes

| Change | Action |
|--------|--------|
| UTF-8 default | Check code that relied on the locale encoding (Windows cp1252 files) |
| `profile` deprecated | Switch to `profiling.tracing` / `cProfile` |
| `__cached__` removed | Use `__spec__.cached` |
| `__loader__` / `__package__` deprecated | Use `__spec__` |
| `import` lines in `.pth` | Deprecated. Use `.start` files with `pkg.mod:callable` (PEP 829) |
| C extensions | `PyGILState_*` soft-deprecated (PEP 788); target `abi3t` for free-threaded builds |
